# Power Electronic Converters for Electric Vehicle Systems using MATLAB & Simulink

**Certification Program**

---

## Overview

Completed a certification program focused on the design and simulation of power electronic converters for Electric Vehicle (EV) systems, using MATLAB and Simulink. The program covered core converter topologies and their application in modern EV powertrains.

## Key Learnings

- Fundamentals of power electronic converters used in EV systems
- Simulation of converter topologies using MATLAB & Simulink
- Practical modeling and analysis of power electronics circuits for EV applications

## Tools & Skills

`MATLAB` `Simulink` `Power Electronics` `Electric Vehicle Systems` `Converter Design`
